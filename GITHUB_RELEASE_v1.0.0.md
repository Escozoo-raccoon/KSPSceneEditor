# KSP Scene Editor v1.0.0

First public release of KSP Scene Editor for Kerbal Space Program 1.

### Highlights
- Edit KSP main-menu scenes directly in-game.
- Keep separate compositions for different native menu states.
- Move Kerbals while preserving their animations.
- Add crafts, celestial bodies, lights, text, free images and custom skyboxes.
- Save multiple compositions, apply them at any time, rename them and delete them.
- Compositions survive gameplay transitions and saved active compositions survive a KSP restart.
- Restore the original KSP scene whenever needed.

### Installation
Copy the included `GameData` folder into your KSP installation.

Required final path:
`GameData/KSPSceneEditor/Plugins/KSPSceneEditor.dll`

### Dependencies
No third-party mod dependency is required.

### Notes
The release intentionally contains no redistributed KSP crafts, planet textures, logos or skyboxes.

See `README.md`, the included user guides and `LICENSE.txt` for details.
